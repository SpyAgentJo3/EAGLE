# EAGLE
This repository contains all information and project files having to do with EAGLE a system designed for recovery and aerodynamic control of suborbital student rockets. EAGLE contains of a self-developed PCB and the mechanical design for a 16cm diameter rocket 

## Repository Structure

The repository is organized into the following main directories:

```text
├── ARCHER
│   ├── CAD Design
│   ├── Documentation
│   │   ├── Circuit Drawing
│   │   ├── Mechanical Design
│   │   ├── PCB
│   │   └── Software
│   ├── PCB Design
│   │   ├── CanSat Shield - Landesysteme v1.0.0
│   │   ├── EAGLE Recovery v1.0.0
│   │   ├── Footprint Library
│   │   ├── KiCAD 3D Models
│   │   ├── PCB Concept v2.0.0
│   │   └── Symbol Library
│   ├── Pyrochannels
│   ├── Simulation
│   ├── Software
│   │   └── EAGLE v1.2.1
│   │       ├── src
│   │       └── test
│   └── Misc
```

The repository contains the following main areas:

- **CAD Design** – CAD models and mechanical design files
- **Documentation** – Technical documentation, circuit diagrams, PCB documentation, and software-related documentation
- **PCB Design** – PCB layouts, libraries, concepts, recovery versions, and related design files
- **Pyrochannels** – Design files and backups related to the pyrochannel system
- **Simulation** – Simulation models and related files
- **Software** – Source code and tests for the project software
- **Misc** – Additional files that do not belong to the other categories
